# Contributing

Fixes, new formats and tools are welcome.

1. Open an issue first for anything larger than a small fix, so we can agree on the approach.
2. Fork the repo, make the change on a branch, and add or update a test in `tests/`.
3. Run `.venv\Scripts\python -m pytest -q` and make sure it passes.
4. Open a pull request describing what changed and how you tested it.
